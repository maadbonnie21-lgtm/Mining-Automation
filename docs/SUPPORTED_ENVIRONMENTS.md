# Supported Environments

Production support is explicit and evidence-based.

## Current status

**No production mining workflow is declared supported yet.**

The repository is in foundation stage. Locations, ores, worlds, client/display configurations, routes, and banking workflows remain development targets until their required validation passes.

## Support record requirements

Each supported workflow must eventually record:
- ore/resource
- mine/location
- bank destination/mechanism
- supported client/window mode
- supported OS/display scaling/resolution assumptions
- required game/client visual settings
- route/landmark data version
- perception dataset/test version
- validation date/build
- acceptance/endurance results
- known non-blocking limitations

Knowledge-base presence alone does not constitute production support.
