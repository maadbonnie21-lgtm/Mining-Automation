# P0 live proof definition — 2026-09-05

Automatic startup is proven only when a real RuneLite session begins from a deliberately unsupported camera/view, software reaches a fresh supported Resource view without manual camera hunting, Inventory is correctly observed, PREP relinquishes authority, and the separately authorized miner produces at least one verified +1 from a strictly newer frame.

A green unit test, synthetic transform, receipt, or camera input dispatch is not real-client proof.
