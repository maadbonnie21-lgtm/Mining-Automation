# Mining Knowledge Base

This directory stores version-controlled, structured knowledge used by the application.

Planned domains include:
- ores/resources
- mines/locations
- banks/deposit mechanisms
- landmarks/checkpoints
- routes
- interfaces
- requirements
- support/validation metadata

Public OSRS references may inform this knowledge, but a location is not production-supported merely because it exists here. Production support requires validated perception, navigation, banking, scheduling/resume, recovery, regression, and end-to-end evidence.
